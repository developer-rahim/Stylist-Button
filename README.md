# Stylist-Button

A collection of custom, reusable button widgets for Flutter.

## Highlights

- Multiple visual treatments — filled, outlined, rounded and icon buttons.
- Configurable labels, icons, colours and loading states.
- Drop-in widgets with no external dependencies.

## Tech Stack

| Concern | Choice |
|---|---|
| UI | Flutter, Material |
| Components | Custom `StatelessWidget` buttons |

## Project Structure

```
lib/
- `stylish button`
```

## Getting Started

### Prerequisites

- Flutter `>= 3.16` (Dart `>= 3.2`)

### Run

```bash
git clone https://github.com/developer-rahim/Stylist-Button.git
cd Stylist-Button
flutter pub get
flutter run
```

### Test

```bash
flutter test
flutter analyze
```

## Notes

The `stylish button` folder contains the widget implementations.
